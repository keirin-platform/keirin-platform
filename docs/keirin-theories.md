# 競輪の通説・セオリーと検証計画

調査日: 2026-10-03。予想サイト、専門紙、入門サイト、データ分析記事で語られている通説を集め、**根拠の強さ**と、**私たちのデータで検証できるか**を整理した。
記事（はてなブログ）の分析テーマの元ネタにもする。

- 「私たちのデータ」は **2026-09-11〜10-02 の22日分（1,641レース）** の簡易集計で、参考値にとどまる。本格的な検証は、2025-12 からのデータが揃う10/24ごろ以降に行う。
- 根拠の強さ: **データあり**（期間・件数つきの集計がある）／**経験則のみ**／**食い違い**（出典によって主張が違う）。

## 前提（検証するときに必ず考慮すること）

### 車番には実力の情報が入っている（番組編成のルールと慣例）
| 事実 | 情報源 | 私たちのデータ |
|---|---|---|
| **ミッドナイトは、競走得点の高い順に内枠（1番車）から並ぶ** | オーナー情報。導入時期は 2020-10 説と 2021-10 説がある（[rin-pedia](https://rin-pedia.com/arekore/midnight_point)、[sog-rc27](https://www.sog-rc27.org/keirinn-syaban/)） | ミッドナイトの 96.2% のレースで車番＝得点順位、1番車は 100% 得点1位。ほかの時間帯で完全に得点順なのは 0% |
| **4・6・8番車には、同じ枠の相方より実力が劣る選手を置く**（9車の枠は 1／2／3／4・5／6・7／8・9。枠連の釣り合いを取るためとみられる） | オーナー情報、[sog-rc27](https://www.sog-rc27.org/keirinn-syaban/)（「ヨーロッパ」と呼ばれる） | 9車: 4<5、6<7、8<9 がどれも **100%**（142レース、平均得点差 5〜9点）。**7車（枠連は売っていない）でも 6<7 が 95.7%**、5<6 は 4.6%（ほかの隣の組は約50%）→ 慣例が6番車にだけ残っている |

→ 「1番車有利」「4・6・8番車は来ない」は、**車番の位置の効果ではなく、実力の配置の効果**。
ミッドナイトを除き、得点1位の選手どうしで比べると、1番車の勝率は 41.2%、7番車 42.5%、2〜5番車 32〜37%（7車）で、1番車がはっきり有利とは言えない。
車番を分析するときは、得点とミッドナイトかどうかをそろえて比べる。

### そのほかの注意
- 2020年後期からは7車立てが主流（コロナ対応）。それより前は9車が中心なので、期間をまたぐ比較では車立てで分ける（[遠山030](https://gamboo.jp/topics/?tid=tohyama030-pc)）。
- 「1番人気」の定義は出典によって違う（選手の単支持率、2車単オッズ、3連単の1番人気の目など）。私たちのデータでは「**払戻の人気＝的中した組番の人気順**」で、「1番人気の目が的中した割合」として扱う（選手ごとのオッズは収集していない）。
- 払戻率は約75%なので、回収率は75%前後が基準になる。

## 検証の優先順位（私たちのデータでできるもの）
1. **競走得点の予測力**（得点1位の勝率、得点差ごとの勝率）。昇降級補正とレーティングによる改善も見る（記事の本命テーマ）
2. **車番の効果**（ミッドナイトのルールと4・6・8番車の慣例をそろえたうえで）
3. **地元選手の有利**（得点や級班をそろえて比べる）
4. **決まり手とバンク**（周長、みなし直線。上の表を使う）
5. **車立て、種目、グレード、時間帯ごとの堅さ**（中央値、1番人気の目の的中率、回収率）
6. **天候、風、季節**（2025-12 からのデータで冬と夏を比べる）
7. **ガールズ**（本命の強さ、決まり手と脚質）
8. **近況、年齢・期別、B・H・Sの回数**

## 今後（データの追加を検討するもの）
- **並び（ライン）**: ライン関係の通説（番手有利、3番手、単騎、競り、ラインワンツー）を検証するには、発走前の並び予想が必要。過去分の応答には入っていないので、当日の出走表を発走前に集める仕組みが要る（アクセス数が増えるので、必要になったら相談する）。
- **オッズ**: 「1番人気の選手」や「人気の割れ方」を扱うには、確定オッズが必要（JST 系の API は未調査）。
- **場の諸元**: 場→都道府県（地元の判定）と、バンクの周長・みなし直線を、コードのデータとして持つ（分析を始めるときに作る）。
