# 相手の強さを考慮したレーティング

オーナーの要望（2026-10-03）: 戦った相手の強さで競走得点を補正したい。→ **レーティング方式**で進める。

## なぜ必要か
- 公式の競走得点は「番組の平均点 ± 2 × 着順差」の平均で、**誰に勝ったか**は反映されない。
- ただし、同じ種目なら出走メンバーの平均得点のばらつきは小さい（標準偏差1〜2点。2026-09-20〜10-01 の実測）。番組の平均点も、ある程度はレベルを反映している。
  → 多くの選手では効果は小さい見込み。効きそうなのは次のような選手:
  - G1・G3 をよく走る選手
  - 級班が変わった選手
  - 斡旋の関係で強い（弱い）メンバーと当たり続けた選手
- 「相手の平均得点で足し引きする」単純補正は、番組の平均点で反映済みの部分を二重に数えてしまうので採らない。

## モデル（`src/keirin/rating.py`）
- **Plackett–Luce**: 選手ごとに強さ γ を持つ。1着から順に、残っている選手の中から γ に比例する確率で決まると考えて、着順全体の尤度を最大化する。
  強い相手に先着すると大きく評価され、弱い相手に負けると大きく下がる。
- 推定方法:
  - Gamma(a=2, b=1) を事前分布とした MAP 推定を、MM アルゴリズム（Hunter 2004、Caron & Doucet 2012）で解く。
  - 各レースは経過日数で重み付けする（半減期は既定 90 日）。
  - **as_of より前のレースだけ**を使う（評価で未来のデータが混ざらないようにするため）。
- 着順がない選手（失格、落車棄権、欠場）はそのレースの順位から除く。ガールズ（L級）は男子と対戦しないので、別のプールとして目盛りを合わせる。
- 表示用には、θ = log γ を、最新の公式得点への線形回帰で「得点換算」にする（プールごと）。

## 級班をまたいだ比較について（重要）
- S級、A級1・2班、A級3班の選手は、ふだん同じレースを走らない。対戦関係がつながっていないと、**それぞれのグループの中でしか比べられない**。事前分布のせいで、どのグループも中心がそろってしまう。
- グループどうしをつなぐのは、**期替わりや特別昇級で、両方の級班を走った選手**。期替わりを含む期間のデータ（2026-06〜07、2025-12〜2026-01）が入って初めて、級班をまたいだ比較になる。
- 2026-10-03 の試算（12日分しかない）では、A3 の上位選手が S1 と同じくらいの値になった。上の理由によるもので、想定どおり。

## 評価
```bash
uv run keirin rating --data-dir ../keirin-data --as-of 2026-11-01 --top 20
uv run keirin evaluate --data-dir ../keirin-data --date 2026-09-01 --to 2026-09-30 --rating
```
- 同じレースの2人を比べて、値が高い方が先着した割合を、公式の得点、級班補正後の得点、レーティングで比べる（同じペアで比べる）。
- 2026-10-03 の試算（12日分、`--include-incomplete`）: 公式 0.675、レーティング 0.592。対戦数が1人あたり5走前後しかないので、まだ参考にならない。
