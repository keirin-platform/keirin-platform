# ラインの位置・人数・競り・地区の検証

本物の並びが1年3か月分そろった（2026-11-12 にオッズパークの遡りが完了）ので、並びを待って保留にしていた keirin-research の候補（CAND-002〜009）を確かめる。
スクリプトは `research.py` の `keirin line-positions`。ここには設計（測る前に決めたこと）と経緯を残し、結果は確かめたあとに追記する。

## 設計メモ（2026-11-16、集計の前に書いた）

### 1. 問い

- 先行の番手が一番有利か（CAND-002）
- 3番手は1着を取りにくいか。3着には多いか（CAND-003）
- 単騎は不利か（CAND-004）
- 競りがあると荒れるか（CAND-006）
- ラインは長いほど有利か（CAND-007）
- 同県・同地区の連携は、近いほど強いか（CAND-008）
- 1着の8割は、バックを取ったラインから出るか（CAND-009）
- 番手捲り（CAND-005）は、主導権を取ったラインのその後を記述するだけにして、判定しない（選手の特徴の分析と合わせる。docs/rider-traits.md）
- ラインの連動（LAW-001）を、登録のあとのデータを含む全期間で確かめ直す（COMMIT-003）

### 2. 効きうる要因と扱い

| 要因 | 扱い |
|---|---|
| 実力（得点） | 位置と実力は結びついている（強い追込が番手を回る、など）。得点だけの順位ロジットで各選手の1着・3着以内の確率を出し、実際との差（超過）で比べる（METH-002、METH-006）。レースの中で超過は足して0になる |
| 得点に入っている「位置の慣れ」 | 得点は着順から付くので、ふだん番手を回る選手の得点には番手の有利がすでに入っている。得点をそろえた比較は、得点に入りきらない分しか測らない。補うために、同じ選手が単騎のときとラインにいるとき（先頭のときと番手のとき）の超過の差も出す（判定には使わない） |
| ラインの位置・人数・競り | 問いそのもの。競りの選手は位置の集計から分けて「競り」として数える。欠場の選手は除いて位置を詰める |
| 主導権（H・B） | CAND-002 の「先行の」、CAND-009、CAND-005 で使う。B・H は先頭の1人しか分からない（BLIND-001） |
| 級班・車立て | 得点だけのモデルを級班ごとに学習する。A級（7車）、S級7車、S級9車に分けても向きが同じかを見る（METH-003） |
| 種目 | 決勝と決勝以外に分けて向きを見る（決勝はラインが決まりにくいと言われる） |
| 昇降級の直後 | 表示得点をそのまま使う（LAW-001 と同じ）。期替わり直後は前の級班の得点が混ざる（RULE-002・003）が、位置の間で偏る理由が見当たらないので、そろえない |
| 車番、時間帯、バンク、天候 | 位置の間で偏る理由が見当たらず、実力は得点でそろえるので、そろえない |
| ガールズ | ラインがないので除く（RULE-009） |
| 並びの取得元 | 2026-10-04 まではオッズパーク、10-05 からは KEIRIN.JP。どちらもレース前の予想。取得元ごとの値も出して、食い違わないかを見る |

### 3. 使う項目と、測りたいものとの差

- 位置: lines 表の `line_pos`・`line_size`・`contested`（本物の並び＝レース前の予想。推定の並びは使わない。DATA-KD-003）。実際にその位置を回ったかは分からない（FIELD-002、未照合）。
  - 先頭: 2人以上のラインの1番目。番手: 2番目。3番手、4番手以降。単騎: 1人だけのライン（並びに載っていない選手も単騎）。
- バックを取った: entries の `bh` に B（残り半周のバックを先頭で通過）。H は残り1周のホーム（FIELD-001・003、未照合）。この期間の男子では、B は全レースに1人、H は 99.4% のレースに1人。
- 強さ: entries の `score`（FIELD-005）。
- 荒れる: payouts の2車単と3連単の払戻金（100円あたり）。選手ごとのオッズはない（BLIND-005）ので、的中した目の払戻で代える。あわせて、得点1位の選手が得点の見込みどおりに勝っているかを見る。
- 地区: entries の `prefecture` と、`lines.REGIONS` の7地区（中国と四国は1つに数える）。同県、同地区（県は違う）、他地区の3つに分ける。同じ競輪場かどうかは持っていない。

### 4. 期間と件数（着順との関係を見る前に数えた）

- 並び: 2025-08-24〜2026-11-15 の449日。男子（S級・A級）で、全員に得点があり3着まで決まったレースは 30,923（A級7車 20,002、S級7車 6,116、S級9車 2,818、欠場などでそれ以外 1,987）。並びのないレースは24だけ。
- 得点だけのモデルの学習: 並びの期間より前の 2025-01-12〜08-23（A級 10,713、S級 4,762 レース）。評価する日より前のデータだけで学習する（METH-005）。
- 競りのあるレース: 443（1.4%）。単騎の選手: 約2.2万人。ライン: 2人 約4.4万、3人 約3.2万、4人以上 約3,500。
- 先頭–番手の組: 同県 16,673、同地区 46,193、他地区 16,079。
- 別のセッションが遡っている 2025-07-17〜08-23 の並びは、まだコミットされていないので使わない。

### 5. 研究の取り決め

- 出すのは集計値だけ（COMMIT-004）。選手の名前・登録番号は出さない。個人差は扱わない。
- オッズパークの並びの文言は載せない（SRC-OP-002）。予想（確率）は今回は扱わない。

- 副の指標（判定しない）: 位置ごとの1着・2着以内・3着以内の率と超過の表、1着に占める位置の割合（文献との比較）、ラインの人数ごとの表、1・2着が同じラインから出た割合、
  同地区 − 他地区の差、3連単の払戻金、得点1位の1着の超過（競りあり − なし）、競りの選手と競られた先頭の超過、同じ選手の中での比較、級班・車立て・種目・取得元ごとの値。
  得点だけのモデルの当てはまり（得点順位ごとの超過）と、得点順位の層でそろえ直した位置の超過も出して、主の指標と向きが同じかを確かめる。
- 検出力: 位置や地区の比較は件数が多く、区間の幅は ±1 ポイント前後の見込み。競りは 443 レースしかなく、払戻金の対数の差の区間は ±0.11 ほどになる見込み（2割くらいの差なら見つけられるが、1割の差は判断できない。METH-001）。
- 同じデータで多くの通説を確かめるので、前半と後半で同じ向きを求める（METH-008）。登録したものは、あとから入るデータで確かめ直す（COMMIT-003）。

### 7. この問いに効く、データから見えないもの

- 並びは予想で、実際の隊列と違う（BLIND-002）。位置の効果とラインの効果は、実際より小さく出る。
- 周回ごとの位置がない（BLIND-001）。「先行した」は B・H の先頭の1人でしか分からず、番手捲りは B で代える。
- 競りの勝ち負け、ブロック、切り替えは見えない（BLIND-003）。競りの選手の成績は、勝った側と負けた側の平均になる。
- 選手ごとのオッズがない（BLIND-005）。「荒れる」は払戻金で代えるが、払戻金には市場が競りを織り込んだ分が入っている。
- 得点には位置の慣れが入っている（上の 2.）。「得点をそろえると差がない」は「位置に有利不利がない」ではない。

## 結論

### 読み方（得点をそろえた比較が測っているもの）

得点は着順から付くので、ふだんの位置の有利不利はすでに得点に入っている。得点をそろえた超過が測るのは「同じ得点の選手どうしで、着順の出方がどう違うか」で、位置の有利そのものではない。

- 先頭は1着が見込みより多く（+3.8）、番手は1着が見込み並みで2着以内が多い（+1.9）。同じ得点なら、自力の選手は「勝つか沈むか」、番手の選手は「2・3着が多い」という出方になる。
- 同じ選手で比べると、番手のときのほうが1着も3着以内もずっと多い（+9.5、+13.7）。ただし選手は、付く相手がいるときに番手を回るので、この差は番手の有利を大きめに見せる。
- どちらも片側に寄った見方で、「番手の有利」の大きさそのものはこのデータでは決められない。予想では、得点に加えて位置とラインの人数を入れると、上の表の分だけ確率が動く。

### 候補ごとの結論

対象はすべて、2025-08-24〜2026-11-15 の男子の、レース前の並びがある 30,923 レース。

1. **先行の番手が一番有利（CAND-002）: 全体では成り立たない。S級では成り立つ。**
   先頭がバックを取ったラインの1着は、A級では先頭に多く（34.1% 対 28.1%）、S級では番手に多い（7車 33.1% 対 22.3%、9車 34.3% 対 18.8%）。S級の番手は得点の見込み（19.2%、17.4%）も大きく上回る。
   文献は「S級9車立てだけ」としていたが、S級7車でも同じだった。確かさ: 層ごとに区間が0を含まず、前半と後半も同じ向き。ただし主の指標は全体で、層別は向きの確認だった。あとから入るデータで確かめ直す。
2. **3番手は1着を取りにくい（CAND-003）: 確認済み。「3着には多い」は見込み並み。**
   1着は 2.7%（見込み 8.1%）。3着以内は 31.8%（見込み 31.4%）で、得点から見込める以上には多くない。4人以上のラインの3番手は3着以内が多い（55.9%／39.2%）。
3. **単騎は不利（CAND-004）: 確認済み。A級で大きく、S級では小さい。**
   3着以内は 27.0%（見込み 34.9%）。同じ選手の中でも同じ大きさ（−7.3）。S級7車は −3.7、S級9車は判断がつかない。
4. **競りがあると荒れる（CAND-006）: 逆だった。**
   2車単の払戻金は競りのあるレースのほうが約16% 低い。競られた先頭が勝ち切ることが多い（1着 65.4%）。A級では区間が0を含まず、S級と9車立ては件数が足りず判断がつかない。
5. **ラインは長いほど有利（CAND-007）: 確認済み。位置の違いより大きい。**
   3人以上のラインの先頭と番手は、2人のラインより1着で +7.0、3着以内で +13.5。2人のラインの番手は見込みを下回る（3着以内 −6.8）。
   ただし、強い先頭ほど後ろに人が付くので、「長いから有利」と「有利な先頭に人が集まる」は分けられない。
6. **同県・同地区ほど連携が強い（CAND-008）: 差は見つからなかった。**
   先頭–番手がともに3着以内に入る超過は、同県・同地区・他地区でほぼ同じ（+11.2、+10.6、+10.8）。区間は ±1 ポイントで、2ポイントの差があれば見つけられた。
7. **1着の8割はバックを取ったラインから（CAND-009）: 約6割だった。**
   61.6%。A級 63.8%、S級 55〜57%、決勝 54.2%。
8. **番手捲り（CAND-005）: 判定していない。** 番手がバックを取る形は 0.7% と少なく、決勝に偏る。起きたときの番手の1着は 46.9%。候補のまま、試算として残す。
9. **ラインの連動（LAW-001）: 1年3か月でも同じ大きさ（+0.508 組／レース）。**

### データから見えないもの

- 並びは予想で、実際の隊列と違う（BLIND-002）。位置とラインの効果は、実際より小さく出ている。
- 周回ごとの位置がない（BLIND-001）。「先行した」は B・H の先頭の1人で代えていて、番手捲りは B で代えている。
- 競りの勝ち負け、ブロック、切り替えは見えない（BLIND-003）。競りの選手の成績は、勝った側と負けた側の平均。
- 選手ごとのオッズがない（BLIND-005）。「荒れる」は的中した目の払戻金で代えた。払戻金には、市場が競りを織り込んだ分が入っている。
- 選手のコメントがない（BLIND-004）。誰がどのラインに付くかは選手が決めるので、ラインの長さや他地区との連携には、選手の見立て（先頭の強さ、相性）が入っている。

## 前受けと突っ張り先行（2026-11-17、オーナーの観察から）

オーナーの観察: 7車立てでラインが2つしかないとき、先行主体のラインが前受けすると、突っ張り先行で別のラインを封じることがよくある。
S は、回数が同じくらいなら内枠が有利（前を取りやすい）。この2つを、データで見える範囲で確かめる。スクリプトは `research.py` の `keirin front-start`。

### 設計メモ（集計の前に書いた）

1. **問い**: 7車立て・2つのラインのレースで、先行主体のラインが前受けしそうなとき、そのラインは得点の見込みより勝つか。相手のラインは上位に来にくいか。
2. **持っていないもの**: そのレースで誰が S を取ったかは、データにない。結果の項目は B・H だけ。
   出走表の S の回数（`start`）を開催をまたいで引き算して復元できるかを、答えの分かる B で試した（2025-08-24 以降）。
   同じ開催の翌日は回数がまったく変わらず（158,204 組すべてで差が0。B を取った翌日も）、出走表の回数は開催の間は固定だった。開催をまたぐと、前の開催の全レース分と、期間から外れた分が混ざる。**レースごとの S は復元できない**。
3. **前受けの見込み**（レース前に分かる値だけで決める）: 出走する選手のうち、出走表の S の回数が最多の選手から2回以内の選手の中で、いちばん内の車番の選手がいるライン（単騎ならその選手）。
   「同じくらいの回数なら内枠」というオーナーの指摘を、2回以内という形にした（S の回数は中央値 2、上位 25% が 5 回以上）。比較のために、「S の回数が最多（同数なら内枠）」の決め方でも出す。
4. **対象**: 男子、本物の並び、7人が出走、2人以上のラインがちょうど2つ（単騎がいてもよい）、競りなし。10,705 レース（単騎なし 1,512、単騎1人 5,761、2人 3,038、3人 394）。
   先行主体のラインは、2つのラインの先頭のうち、出走表の B の回数が多い方（同数の 572 レースは除く → 10,133 レース）。2つの決め方で前受けの見込みが違うのは 1,756 レース。
5. **そろえる要因**: 実力は、得点だけの順位ロジット（並びの期間より前で学習）の見込みとの差で見る（位置の検証と同じ）。A級と S級、単騎のないレース、S の回数の差（2つのラインの最大値の差が2回以内か、3回以上か）に分けても向きが同じかを見る。
   車番には実力の配置が入っている（MECH-003）が、得点の見込みとの差を取るので、車番そのものの有利は残りうる（CAND-031 は保留のまま）。
6. **測る前に決めた基準**（COMMIT-002。95% 区間はレース単位のブートストラップ 2,000 回・seed 0、前半と後半は日付の中央値）
   - 主の指標: 先行主体のラインから1着が出る割合の超過（実際 − 得点だけの見込み）の差（そのラインが前受けの見込みのとき − 相手のラインが前受けの見込みのとき）。実質的な大きさ 0.03、観察どおりなら正。
   - 副の指標（判定しない）: 先行主体のラインの先頭が H と B の両方を取った割合（主導権を取り切った。突っ張りと押さえ先行は区別できない）、相手のラインの3着以内の人数の超過、相手のラインが3着以内に1人も入らない割合、単騎が前受けの見込みのレース、決め方（最多）での値、上の層ごとの値。
   - 内枠の効き方は、S の回数の差が2回以内のレース（前受けの見込みが車番で決まる）と、3回以上のレース（回数で決まる）に分けた値で見る。
7. **見えないもの**: 前受けは見込みで、実際に誰が前を取ったかは分からない（BLIND-001）。見込みが外れた分だけ、差は小さく出る。突っ張ったのか、後ろから押さえて先行したのかは区別できない（BLIND-003）。
   作戦（前を取りたいか、後ろから攻めたいか）は選手のコメントにあるが、持っていない（BLIND-004）。並びは予想（BLIND-002）。
