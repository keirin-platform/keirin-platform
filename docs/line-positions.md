# ラインの位置・人数・競り・地区の検証

本物の並びが1年3か月分そろった（2026-11-12 にオッズパークの遡りが完了）ので、並びを待って保留にしていた keirin-research の候補（CAND-002〜009）を確かめる。
スクリプトは `research.py` の `keirin line-positions`。ここには設計（測る前に決めたこと）と経緯を残し、結果は確かめたあとに追記する。

## 設計メモ（2026-11-16、集計の前に書いた）

### 1. 問い

- 先行の番手が一番有利か（CAND-002）
- 3番手は1着を取りにくいか。3着には多いか（CAND-003）
- 単騎は不利か（CAND-004）
- 競りがあると荒れるか（CAND-006）
- ラインは長いほど有利か（CAND-007）
- 同県・同地区の連携は、近いほど強いか（CAND-008）
- 1着の8割は、バックを取ったラインから出るか（CAND-009）
- 番手捲り（CAND-005）は、主導権を取ったラインのその後を記述するだけにして、判定しない（選手の特徴の分析と合わせる。docs/rider-traits.md）
- ラインの連動（LAW-001）を、登録のあとのデータを含む全期間で確かめ直す（COMMIT-003）

### 2. 効きうる要因と扱い

| 要因 | 扱い |
|---|---|
| 実力（得点） | 位置と実力は結びついている（強い追込が番手を回る、など）。得点だけの順位ロジットで各選手の1着・3着以内の確率を出し、実際との差（超過）で比べる（METH-002、METH-006）。レースの中で超過は足して0になる |
| 得点に入っている「位置の慣れ」 | 得点は着順から付くので、ふだん番手を回る選手の得点には番手の有利がすでに入っている。得点をそろえた比較は、得点に入りきらない分しか測らない。補うために、同じ選手が単騎のときとラインにいるとき（先頭のときと番手のとき）の超過の差も出す（判定には使わない） |
| ラインの位置・人数・競り | 問いそのもの。競りの選手は位置の集計から分けて「競り」として数える。欠場の選手は除いて位置を詰める |
| 主導権（H・B） | CAND-002 の「先行の」、CAND-009、CAND-005 で使う。B・H は先頭の1人しか分からない（BLIND-001） |
| 級班・車立て | 得点だけのモデルを級班ごとに学習する。A級（7車）、S級7車、S級9車に分けても向きが同じかを見る（METH-003） |
| 種目 | 決勝と決勝以外に分けて向きを見る（決勝はラインが決まりにくいと言われる） |
| 昇降級の直後 | 表示得点をそのまま使う（LAW-001 と同じ）。期替わり直後は前の級班の得点が混ざる（RULE-002・003）が、位置の間で偏る理由が見当たらないので、そろえない |
| 車番、時間帯、バンク、天候 | 位置の間で偏る理由が見当たらず、実力は得点でそろえるので、そろえない |
| ガールズ | ラインがないので除く（RULE-009） |
| 並びの取得元 | 2026-10-04 まではオッズパーク、10-05 からは KEIRIN.JP。どちらもレース前の予想。取得元ごとの値も出して、食い違わないかを見る |

### 3. 使う項目と、測りたいものとの差

- 位置: lines 表の `line_pos`・`line_size`・`contested`（本物の並び＝レース前の予想。推定の並びは使わない。DATA-KD-003）。実際にその位置を回ったかは分からない（FIELD-002、未照合）。
  - 先頭: 2人以上のラインの1番目。番手: 2番目。3番手、4番手以降。単騎: 1人だけのライン（並びに載っていない選手も単騎）。
- バックを取った: entries の `bh` に B（残り半周のバックを先頭で通過）。H は残り1周のホーム（FIELD-001・003、未照合）。この期間の男子では、B は全レースに1人、H は 99.4% のレースに1人。
- 強さ: entries の `score`（FIELD-005）。
- 荒れる: payouts の2車単と3連単の払戻金（100円あたり）。選手ごとのオッズはない（BLIND-005）ので、的中した目の払戻で代える。あわせて、得点1位の選手が得点の見込みどおりに勝っているかを見る。
- 地区: entries の `prefecture` と、`lines.REGIONS` の7地区（中国と四国は1つに数える）。同県、同地区（県は違う）、他地区の3つに分ける。同じ競輪場かどうかは持っていない。

### 4. 期間と件数（着順との関係を見る前に数えた）

- 並び: 2025-08-24〜2026-11-15 の449日。男子（S級・A級）で、全員に得点があり3着まで決まったレースは 30,923（A級7車 20,002、S級7車 6,116、S級9車 2,818、欠場などでそれ以外 1,987）。並びのないレースは24だけ。
- 得点だけのモデルの学習: 並びの期間より前の 2025-01-12〜08-23（A級 10,713、S級 4,762 レース）。評価する日より前のデータだけで学習する（METH-005）。
- 競りのあるレース: 443（1.4%）。単騎の選手: 約2.2万人。ライン: 2人 約4.4万、3人 約3.2万、4人以上 約3,500。
- 先頭–番手の組: 同県 16,673、同地区 46,193、他地区 16,079。
- 別のセッションが遡っている 2025-07-17〜08-23 の並びは、まだコミットされていないので使わない。

### 5. 研究の取り決め

- 出すのは集計値だけ（COMMIT-004）。選手の名前・登録番号は出さない。個人差は扱わない。
- オッズパークの並びの文言は載せない（SRC-OP-002）。予想（確率）は今回は扱わない。

### 6. 測る前に決めた基準

判定は COMMIT-002（95% 区間はレース単位のブートストラップ 2,000 回・seed 0。前半と後半は日付の中央値で分ける。区間が ±実質的な大きさの内側なら「実質的な差なし」を先に取る）。

| 候補 | 主の指標 | 実質的な大きさ | 通説どおりなら |
|---|---|---|---|
| CAND-002（a） | 競りのないラインで、1着の超過の差（番手 − 先頭） | 0.02 | 正 |
| CAND-002（b） | 先頭がバックを取ったラインで、1着率の差（番手 − 先頭。文献と同じく得点はそろえない） | 0.03 | 正 |
| CAND-003 | 3番手の1着の超過 | 0.02 | 負 |
| CAND-003（3着） | 3番手の3着以内の超過 | 0.03 | 正 |
| CAND-004 | 単騎の3着以内の超過 | 0.03 | 負 |
| CAND-004（1着） | 単騎の1着の超過 | 0.02 | 負 |
| CAND-006 | 2車単の払戻金の対数の差（競りあり − なし。級班と車立ての層でそろえる） | 0.10 | 正 |
| CAND-007 | 先頭と番手の超過の差（3人以上のライン − 2人のライン）。1着と3着以内 | 0.02、0.03 | 正 |
| CAND-008 | 先頭–番手の組がともに3着以内に入る超過（実際 − 得点だけの見込み）の差（同県 − 他地区） | 0.02 | 正 |
| CAND-009 | 1着が、バックを取った選手のライン（単騎なら本人）から出た割合 | 区間が 0.75〜0.85 の内側なら確認済み、上限が 0.75 未満なら否定 | 0.80 |

- 副の指標（判定しない）: 位置ごとの1着・2着以内・3着以内の率と超過の表、1着に占める位置の割合（文献との比較）、ラインの人数ごとの表、1・2着が同じラインから出た割合、
  同地区 − 他地区の差、3連単の払戻金、得点1位の1着の超過（競りあり − なし）、競りの選手と競られた先頭の超過、同じ選手の中での比較、級班・車立て・種目・取得元ごとの値。
  得点だけのモデルの当てはまり（得点順位ごとの超過）と、得点順位の層でそろえ直した位置の超過も出して、主の指標と向きが同じかを確かめる。
- 検出力: 位置や地区の比較は件数が多く、区間の幅は ±1 ポイント前後の見込み。競りは 443 レースしかなく、払戻金の対数の差の区間は ±0.11 ほどになる見込み（2割くらいの差なら見つけられるが、1割の差は判断できない。METH-001）。
- 同じデータで多くの通説を確かめるので、前半と後半で同じ向きを求める（METH-008）。登録したものは、あとから入るデータで確かめ直す（COMMIT-003）。

### 7. この問いに効く、データから見えないもの

- 並びは予想で、実際の隊列と違う（BLIND-002）。位置の効果とラインの効果は、実際より小さく出る。
- 周回ごとの位置がない（BLIND-001）。「先行した」は B・H の先頭の1人でしか分からず、番手捲りは B で代える。
- 競りの勝ち負け、ブロック、切り替えは見えない（BLIND-003）。競りの選手の成績は、勝った側と負けた側の平均になる。
- 選手ごとのオッズがない（BLIND-005）。「荒れる」は払戻金で代えるが、払戻金には市場が競りを織り込んだ分が入っている。
- 得点には位置の慣れが入っている（上の 2.）。「得点をそろえると差がない」は「位置に有利不利がない」ではない。
