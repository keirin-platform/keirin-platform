# 予想（1着・2着以内・3着以内の確率）

オーナーの要望（2026-10-05）: 出走表から、各選手が1着になる確率、3着以内に入る確率を出したい。
**車券や回収率ではなく、確率で**。→ ビューアの「予想」タブとして組み込む。

## 試作と検証（2026-10-05）
武雄・小松島のミッドナイト（各7レース）で、スクラッチの試作を当夜に動かして確かめた。

- 対象: A級7車のレース（収集済みは 2026-08-18〜10-04 の 2,198 レース）。
- 検証: 8/18〜9/27 で学習し、学習に使っていない 9/28〜10/4 の 300 レースで評価した。当夜の予想は、10/4 までの全レースで学習し直したモデルで出した。
  - 1着の対数損失: **1.494**（得点だけのモデルは 1.579、全員同じ確率なら 1.946）
  - 較正: 予測した確率と実際の割合は、ほぼ一致した（例: 1着45%以上と予測した選手の実際の1着率は 59%、予測の平均は 60%）。
- 当夜の14レース
  - 1着の対数損失: 1.456（出走表だけ 1.477、得点だけ 1.564）
  - 本命の1着: 6/14（期待値 5.1）。上位3人の3着以内: 23/42（期待値 24.7）。
  - 単純な決め方との比較: 1番車（得点1位）の1着は 7/14。「誰が来るかを1人選ぶ」精度では、単純な決め方と変わらない。このモデルの強みは確率の正確さ。
- 弱点: ラインの上位独占（同じラインで1〜3着）を表せない。選手を1人ずつ独立に扱うため（小松島6R、7R）。

## モデル（`src/keirin/predict.py`）
- **Plackett–Luce（順位ロジット）**: 1着から順に、残った選手の中から exp(効用) に比例する確率で決まると考える。
  - 2着・3着は、効用に温度 t2、t3 を掛けて選ぶ（下の着ほどまぎれが大きい。学習では t2 ≈ 0.6〜0.85、t3 ≈ 0.45〜0.53）。
  - ライン効果は、1着用（γ1）と2・3着用（γ23）を分ける。3番手は1着を取りにくいが、3着には多いため。
- **効用** = 出走表の特徴 × β + ラインの特徴 × γ
  - 出走表の特徴: 競走得点（レース内の平均との差）、得点なし、勝率・2連対率・3連対率、脚質（逃・両）、
    B・H・S の回数（log1p）、決まり手の傾向（log1p(逃+捲) − log1p(差+マ)）、年齢、前期がS級。
  - ラインの特徴: 番手、3番手以降、単騎、番手×先頭の強さ（先頭の得点の差）、3番手以降×先頭の強さ、
    先頭×（ラインの人数 − 2）、先頭が追込。
- **グループ**: S級、A級、L級（ガールズ）で別々に学習する。種別（`race_class` の先頭）で分ける。
  - ガールズはラインがないので、並びを推定せず、学習でも予想でも全員を単騎として扱う（ラインの重みは 0 になる）。
- **学習**: 1〜3着の着順の尤度を最大化する（L-BFGS、解析的な勾配、小さい L2 正則化）。
  - 欠場の選手は除き、並びの位置を詰める（番手が欠場したら3番手が番手になる）。成績のない選手が混じるレースと、着順のついた選手が3人未満のレースは使わない。
  - 同着は車番の順に並べて扱う（3着以内の同着は 3,692 レース中 33 レースで、影響は小さい）。
  - **学習に使うのは直近 120 日**（`predict.TRAINING_DAYS`）。backfill が終わるとデータは約 2.6 万レースになり、全部で学習すると約 18 秒（手元）かかるため。
- **並び**: 学習では、lines テーブル（keirin.jp の並び予想、オッズパーク）があればそれを使い、なければ**府県（地区）から推定した並び**を使う（`lines.guess_formation`）。
  - 推定の規則: 同じ地区の選手で1つのラインを作る。先頭は脚質（逃 > 両 > 追）、同じなら B の多い方。残りは得点の順。
    1人だけの追込は、同じ方面（東・中・西）のラインの後ろに付ける（4人まで）。付けるラインがない追込どうしは、同じ方面なら1つのラインになる（例: 福岡の逃げ、埼玉の追込、千葉の追込 → 1 / 23）。それでも1人なら単騎。
  - 今夜の14レースで、位置（先頭／番手／3番手以降／単騎）の一致は 82%。推定の並びで学習するので、ライン効果は控えめに出る。
  - 本物の並びは、オッズパークの並びの backfill がそろう 2027-01 ごろから、学習の大半で使えるようになる。
- **確率**: 1着は効用の softmax。2着以内・3着以内は、上位3人の順列をすべて足す（9車でも 504 通り）。

## ビューア
- 「出走表」「予想」「結果」の3タブにする。予想タブは、1着・2着以内・3着以内の確率をバーで表示する。結果が出ていれば着順も並べる。
- 並びは、出走表の上の並び（keirin.jp の並び予想、または収集済みの並び）を使う。なければ府県から推定して、その旨を表示する。並びに載っていない選手は単騎として扱う。
- 欠場の選手は除いて計算する（収集済みの日は個人状況、当日は keirin.jp の出走表一覧または出走表の「(欠場)」）。追加のアクセスはない（表示に使う応答をそのまま使う）。
- 得点のない選手（新人など）は、レースで最も低い得点より3点低いとして計算し、その旨を表示する。
- モデルは、ビューアの起動時（データが更新されたとき）に、直近 120 日のデータで学習してキャッシュする（今は約3秒）。GitHub Actions は使わない（Actions の minutes に余裕がないため）。学習に失敗したら、予想タブにエラーを出し、ほかのタブはそのまま使える。
- **過去の日の予想は参考値**。その日のレースも学習に入っているため（キャプションで明示する）。当日・翌日の予想は、学習に使っていないレースへの予想になる。

## 評価
```bash
uv run keirin predict-eval --date 2026-09-28 --to 2026-10-04 --data-dir ../keirin-data
```
`--date` の前の `--days` 日（既定はビューアと同じ 120 日）のレースで学習し、期間のレースで評価する。グループごとに、1着の対数損失、3着以内・2着以内のブライアスコア、較正の表を出し、得点だけのモデルと全員同じ確率の場合と比べる。

2026-10-05 の結果（8/18〜9/27 で学習、9/28〜10/4 で評価。どれも小さいほど良い）:

| グループ | レース | 1着の対数損失（モデル／得点だけ／全員同じ） | 3着以内のブライアスコア（モデル／得点だけ） | 2着以内のブライアスコア（モデル／得点だけ） |
|---|---|---|---|---|
| A級 | 310 | **1.490** ／ 1.582 ／ 1.939 | **0.199** ／ 0.207 | **0.156** ／ 0.167 |
| S級 | 155 | **1.650** ／ 1.705 ／ 2.035 | **0.199** ／ 0.201 | **0.154** ／ 0.158 |
| L級 | 50 | **0.932** ／ 0.970 ／ 1.937 | 0.148 ／ 0.148 | 0.131 ／ **0.129** |

- 較正（A級）: 1着の予測 0.594 の群で実際は 0.587、3着以内の予測 0.722 の群で実際は 0.718 など、おおむね合っている。
- **この表はやや甘い**: 特徴と正則化の強さは、同じ 9/28〜10/4 の結果を見ながら決めた。10/5〜10/11 が収集されたら（10/12 ごろ）、その期間で確かめ直す。
- 学習時間: 3,690 レースで約3秒（解析的な勾配。スクラッチの試作は数値微分で約60秒かかった）。約 2.6 万レースでは約 18 秒、メモリは約 130MB（手元）。

## 試したこと
### マークの回数（追走の技術）を2・3着用の特徴にする（2026-10-06、入れない）
- 動機（オーナーの観察）: ガールズは横の動きが禁止されているので、強い自力選手の後ろを、自力のない選手が取り合う。位置取りや追走の技術が効いているのではないか。
- データの形: ガールズの2着の決まり手は「マーク」が 43%（A級 42%、S級 36%）。得点4〜7位のガールズで、出走表のマークの回数が0回の選手の2着は 4%、1〜2回は 9%、3回以上は 10%（A級では差がない）。
- 試した特徴（1着用と2・3着用で別の重み）: V2 = log1p(マーク)、V3 = 連対のうちマークの割合。学習した2・3着用の重みは、ガールズで大きなプラス（V2 で +0.58、V3 で +0.76）になった。
- 週ごとの交差検証（3,690 レースすべて。各週を、ほかの週で学習したモデルで予想する）での、追加なしとの差（マイナスが改善）:

  | | ガールズ 2着以内のブライア | ガールズ 1着の対数損失 | A級 1着の対数損失 | S級 1着の対数損失 |
  |---|---|---|---|---|
  | V2 | +0.0002 ± 0.0003 | −0.0045 ± 0.0059 | −0.0013 ± 0.0010 | −0.0018 ± 0.0009 |
  | V3 | +0.0002 ± 0.0002 | +0.0016 ± 0.0054 | −0.0019 ± 0.0014 | −0.0018 ± 0.0022 |

- 結論: 改善は誤差の範囲なので入れない。マークの回数は2連対率と強く結びついていて（得点4〜7位のガールズの2連対率の平均は、マーク0回 5.5%、1〜2回 15.2%、3回以上 23.5%）、モデルにはもともと2連対率・3連対率と「差し＋マーク」の回数が入っているため。
- backfill のあと（ガールズが約6倍になる）に、もう一度確かめる。
