# 追走の千切れ（番手捲りなどで後ろが離される）

オーナーの観察（2026-11-06）から始めた検証。先頭側が捲りで勝つと、同じラインの後ろの選手は離されやすいか。
結果は keirin-research の LAW-002・LAW-003 と CAND-037 に登録した。ここには経緯と手順を残す。

## きっかけ

- 同じ2人の連携で、捲りのときに後ろが3着圏外に落ちる、という印象。過去の連携は5回で、捲りのときは2回とも千切れていた。
- ペア単位の履歴は件数が少なすぎる（4〜5件）ので、選手ごとの特性と、展開・ラインの条件に分けて扱う。

## 定義（オーナー指定）

- 強い千切れ: ラインの先頭側が捲りで1着になり、同じラインの後ろの選手が3着圏外（中止・失格・落車で着順のない選手と、競りの選手は除く）。
- 離された3着（着差が大きい3着）は、この定義では拾えない。探索として、同じ着順の中での勝者との差の位置（パーセンタイル）を見る案がある（事例を見てから作るので、確認には新しいデータが要る）。

## データ

- 並び: 2025-08-24〜2026-11-04 の約3.3万レース。2026-10-05 以降は keirin.jp（レース前の予想）、それ以前はオッズパーク（手元から 2026-11-07〜12 に取得。docs/lines.md）。
- 対象: 男子（S級・A級）。ガールズにはラインがない。
- 着差（margin）は、前の着順との差。勝者との差は足し上げて出す。大差は10車身で打ち切る。

## 手順と結果（`keirin chase-break --date 2025-08-24 --to 2026-11-04`）

基準は集計の前に決めた（実質的な大きさ: 捲りと逃げ勝ちの差は5ポイント、要因ごとの効果は3ポイント）。判定は keirin-research の COMMIT-002。

1. 母数: 並びつき 30,608 レース、勝者のラインの後ろの選手 35,340 人。
2. 捲り勝ちの後ろと逃げ勝ちの後ろの強い千切れ率を、後ろの得点順位・勝者との間隔・車立てをそろえて比べた: +13.1 ポイント（区間 11.8〜14.4、前半 +13.7、後半 +12.5）→ 確認済み（LAW-002）。
3. 要因を同時に入れた回帰（平均限界効果）: 自分のライン人数 +1 人で −5.4、相手の最長ライン +1 人で +4.6、得点差 +5 点で −2.3 ポイント → 3つとも確認済み（LAW-003）。
4. 追走力の個人差: 全期間 p=0.0005、前半 p=0.0005、後半 p=0.72。要因をそろえても同じ。基準（3つとも p<0.05）を満たさず保留（CAND-037）。

要因（相手の強さ、ライン数、相手の最長ライン）は、オーナーの指摘で順に加えた。ライン数（二分戦か三分戦か）は ±1 ポイントでほぼ効かず、回帰には入れていない。

## 注意

- 並びは予想で、千切れは着順の代用（BLIND-001・002）。包まれた場合やブロックと区別できない（BLIND-003）。
- 要因は一度データを見てから選んだので、2026-11-05 以降のデータで確かめ直す（COMMIT-003）。
- 個人差は選手あたりの件数が少ない（中央値6）。2027-04 ごろ、半年分たまったところで見直す。
- ビューアや予想への組み込みは未定。予想には、ラインの連動の2段階モデル（TODO）と合わせて、捲り勝ちの後ろの落ち方を特徴にする案がある。
