# 競走得点の昇降級補正

オーナーの最大の目的: **昇級・降級の影響を補正した競走得点を、出走表で確認したい**（2026-10-02）。

## 1. 競走得点の仕組み（調査結果、2026-10-02）

### 1走ごとの点数
- レースごとに「平均点」があり、中間の着順（9車立は5着、7車立は4着）がちょうど平均点になる。
- 着順が1つ違うごとに±2点。9車立なら1着＝平均＋8、9着＝平均−8。7車立なら±6。
- 平均点は番組（グレード×種目×車立×日制）ごとに決まっている。出典は keirin.jp 資料室の「概定番組」PDF（<https://keirin.jp/pc/dfw/portal/guest/data/prize/2026/2026.html>）。
- 同じ種目で比べると、級班による水準差がある（2026年6月版の1着の点数）:

| 種目 | S級F1 (7車) | A級1・2班F1 (7車) | A級3班チャレンジ |
|---|---|---|---|
| 決勝 | 120 | 104 | 88〜89 |
| 準決勝 | 112 | 96 | 81〜82 |
| 予選 | 102 | 88 | 75 |
| 一般 | 101〜102 | 86〜87 | 73〜74 |

  → S級とA級1・2班の差は約14〜16点。A級1・2班とA級3班の差も約13〜16点。L級（ガールズ）は50〜60点台で、別の体系。
- 2026-06-30 に改定: A級の上位種目 +1、A級3班 +1〜2、L級 +1。S級は変更なし。
- 失格、棄権（落車などによる競走中止）、250競走などは平均から外れる。

### グレードによる平均点の違い（2026-10-31 に概定番組 PDF で確認）
- 同じ級班でも、グレードが上がるほど平均点が高い。S級の決勝のレース平均点（中間着順の点数）:

| グレード | 番組 | 決勝の平均点 |
|---|---|---|
| G1 | 日本選手権（9車立） | 129 |
| G2 | 共同通信社杯（9車立） | 127 |
| G3 | S級 12R 4日制（9車立） | 119 |
| F1 | S級 7R 4日制（7車立） | 114 |

  - 予選・一般などの下位の種目も同じ傾向。G1（日本選手権）の一般は約106〜112、G3 の一般は約94〜95、F1 の一般は約95〜96で、G3 と F1 の一般はほぼ同じ。
  - 同じ着順なら、高いグレードのほうが点が高い。ただし相手も強いので着順は落ちやすい。
- 1走の重みは、グレードによらず窓内の単純平均で等しい。取鳥 雄吾（S1。G1・G3 が多い）の試算では、窓28走のうち G1 の4走は約14%の重みで、平均より10点多く取っても +1.4 点。
- 読み取りの制約: G1 は日本選手権だけ。平均点はトーナメント図の文字から読んだ（表の機械的な抽出ではない）。F1 は7車立、G1〜G3 は9車立で、車立の差が混ざっている。
- 窓の切り替わりは、開催の最終日が属する月（または開始日が属する月）の窓で計算されているように見える（確認は未了）。月をまたぐ開催では、そのため窓から古い月が抜ける。

### 短期間に得点が大きく動く例（2026-10-31 の調査）
- 収集済みの 2025-08〜2026-10 で、同じ級班の選手の月間の得点変化を調べた。窓内の出走数が25走以上あると、5点以上動くのは0.1%（23組）だけ。窓内の出走数が少ない（16走以下）と動きが大きく、8走以下では21%が5点以上動く。
- 5点以上動いた23組のうち19組は、前期と今期で級班が違う（昇降級の影響。全体では26%）。前期と同じ級班は4組だけで、次のとおり説明がついた:
  - 邊見 竜馬（A2）: デビュー直後で窓がまだ埋まっておらず、勝った走りだけが足された。4月は A3 で、A3 の走りが窓から抜けると平均が上がる。5月に期の途中で A3 から A2 に上がっている（特別昇級とみられる）。
  - 齋藤 登志信（S2）: 2026-04 に8走で1着なし（平均7.0着）、落車棄権の直後。
  - 取鳥 雄吾（S1）: 2026-05 は G1 の好成績と、窓から悪い月（2月）が抜けたことの両方。
  - 小林 潤二（S2）: 休養や落車棄権のあと、窓から悪い月が抜けた（確認は未了）。
- 異常値として外すなら、デビューから4ヶ月以内、昇降級の直後、休養明けを条件にするのが自然。

### 出走表の得点（直近4ヶ月）
- **当月＋前の3ヶ月**（暦月単位）の平均。10月なら7/1〜。
  - JSJ067 の推移で確認した: 9月時点では6月のレースがある選手だけ「4ヶ月」と「今期のみ」が食い違い、10月には全員一致する。
- 出走表の値は「直前に終わった開催」までの値。開催の途中で走ったレースは、その開催が終わるまで反映されない。

### 級班が変わったときの扱い
- **換算の規定はない**（業務方法規程 付録第1）。前の級班で取った点が、そのまま平均に入る。
- 級班は前期（1〜6月）と後期（7〜12月）で替わる。決まるのは前々期の成績。
  - そのため、**1月〜3月と7月〜9月**の出走表には前の級班の点が混ざる。4月と10月以降は新しい級班の点だけになる。
- 特別昇級（3場所連続完全優勝など）は期の途中でも即日。そのあと4ヶ月は混ざる。
- keirin.jp の選手プロフィールには「今期得点」（今期分だけの平均）もある（JSJ067 の `konkiTokuten`）。

- 業務方法規程 <https://www.keirin-autorace.or.jp/documents/www/regulation/keirin/gyoumu.pdf>
- 広報KEIRIN 第213号、第218号
- keirin.jp 出走表の見方、資料室
- 遠山競輪研究所030 <https://gamboo.jp/topics/?tid=tohyama030-pc>（二次情報）

## 2. 実データで見た昇降級組の得点（2026-10-02）

JSJ067（開催ごとの「4ヶ月」と「今期のみ」の得点）で抜き取り確認した:

| 移動 | 例 | 前の級班での得点 → 新しい級班だけの得点 |
|---|---|---|
| A1→S2 | 3名 | 90〜92 → 94〜97（**上がる**） |
| S2→A1 | 2名 | 93〜96 → 87〜91（**下がる**） |
| A2→A3 | 3名 | 78〜84 → 65〜74（**大きく下がる**） |

同じ種目の点数差（約15点）よりは小さい。級班が上がると着順が悪くなるためで、表の差をそのまま足し引きしてはいけない。

## 3. 補正方法

窓（当月＋前3ヶ月）にある得点対象レースのうち、**今の級班と違う tier で走ったレースを、今の tier での期待値に置き換える**:

```
補正得点 = 公式の得点 + Σ Δ(そのレースの tier → 今の tier) ÷ 窓内の得点対象レース数
```

- tier: S（SS、S1、S2）／A12（A1、A2）／A3。S1↔S2 と A1↔A2 は同じ番組を走るので補正しない。L級は対象外。
- Δ は「同じ選手が1つ上（下）の tier で走ったときの、1走あたりの得点の変化」。隣り合わない tier の間は足し合わせる（A3→S ＝ A3→A12 ＋ A12→S）。
- レースごとの tier は、収集した出走表のそのレース時点の級班から決める。追加のアクセスは要らない。
- 現在の開催のレース（同じ場で6日以内）は、公式の得点にまだ入っていないので数えない。
- 窓の全日程を収集していない場合は `complete=False` にする（補正値は参考扱い）。

### Δ の値
| 移動 | 値 | 2026-01 の期替わり | 2026-07 の期替わり | 旧・暫定値（遠山030） |
|---|---|---|---|---|
| A12 → S | +6.18 | +6.51（誤差 0.26） | +5.85（0.26） | +3.80 |
| S → A12 | −5.37 | −5.80（0.25） | −4.76（0.30） | −3.69 |
| A3 → A12 | +9.13 | +9.54（0.27） | +8.59（0.31） | +8.52 |
| A12 → A3 | −9.38 | −9.71（0.32） | −7.73（0.72） | −9.42 |

**2026-10-25 に自分たちのデータで推定し直した**。2回の期替わり（2026-01、2026-07）の推定値を、誤差の逆数の二乗で重みづけして合わせた。
旧値より、A12↔S の差が大きい（約1.6〜1.7倍）。2回の推定の間でも、S→A12 は誤差の2.7倍ずれていて（点数表の改定の影響か、期ごとのばらつきか）、
期替わりごとに再推定する方針は続ける。

評価（ペアの的中率、補正後。旧値 → 新値）: 2026-05〜06 の補正が入ったペア 0.6540 → 0.6611、2026-09 全体 0.6822 → 0.6816、2026-10 全体 0.6783 → 0.6782。
**9・10月はほぼ変わらず（差 0.001 未満）、5〜6月だけ改善した**（1月の期替わりの推定を含むので、サンプル内の評価）。補正の効果は小さく、Δ の値の違いは的中率にはほとんど響かない。

再推定の手順（旧値は古く、2026-06 の点数表改定より前のデータだった）:

```bash
uv run keirin estimate-deltas --boundary 2026-07-01 --data-dir ../keirin-data
```

- old ＝ 6月の出走表の得点（窓は3〜6月で、前の級班だけ）。new ＝ 10月の出走表の得点（窓は7〜10月で、新しい級班だけ）。
- 平均への回帰は、同じ tier に残った選手の (new − old) を old に回帰させて差し引く。
- 点数表の改定（A級 +1）の影響も、この差し引きで打ち消される（Δ は改定後の水準で出る）。
- 必要なデータ: 6月分（backfill で 10/14 ごろに揃う）と、10月分の出走表（日々たまる）。**10月下旬に推定する**。

### 検証
```bash
uv run keirin evaluate --date 2026-09-01 --to 2026-09-30 --data-dir ../keirin-data
```
- 同じレースの2人を比べて、得点が高い方が先着した割合（ペアの的中率）を、公式と補正後で比べる。
- 補正が入ったレース（affected）だけでも集計する。9月分は窓が6〜9月なので、6月分が揃えば評価できる。
